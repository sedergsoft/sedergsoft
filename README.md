## 🚀 En construcción

**SEDERG_PAY** — plataforma de gestión y conciliación de remesas entre Rusia y Cuba: cotización en vivo, trazabilidad por operación, KYC con escaneo antimalware, control de seguridad y panel administrativo. El código está en un repositorio privado; el producto tiene demostración pública:

[🚀 Demo en vivo](https://sedergsoft.github.io/SedergPay_oficial/) · [🔌 Estado de la API](https://5-22-219-30.sslip.io/health) · [💬 Contactar para saber más](https://t.me/sederg)

<details>
<summary><b>Ver capacidades del producto</b></summary>

- Cotizaciones con tasa oficial, comisión configurable y límites por par.
- Remesas con máquina de estados: cotización → orden → depósito → cumplimiento → conciliación.
- KYC con validación de firma real de archivo, escaneo **fail-closed** y cifrado en reposo.
- Seguridad de cuenta: 2FA TOTP, códigos de recuperación y auditoría.
- Ledger con partida doble, idempotencia y saldos verificables.
- Interfaz en español y ruso; despliegue automatizado con TLS.

</details>
